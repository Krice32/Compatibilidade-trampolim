# Trampolim — protótipo integrado

Protótipo navegável das jornadas de empresa e cidadão, com criação de currículos e vagas, compatibilidade vaga-candidato, candidatura, agenda de entrevistas e gestão do processo seletivo.

## Documentação

A referência funcional e técnica canônica está em [DOCUMENTACAO_PROJETO_TRAMPOLIM.md](DOCUMENTACAO_PROJETO_TRAMPOLIM.md).

## Execução

```bash
npm install
npm run dev
```

- Empresa: `?perfil=empresa`
- Cidadão: `?perfil=cidadao`

## Validação

```bash
npm test
npm run build
```
